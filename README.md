# 宿舍 · 穗织

一个可以走进去逛的 three.js 场景：穗织山道旁那户带院子的老宅子，丛雨和亚托莉在里面作伴。

## 怎么打开

不需要安装任何依赖，three.js 已经放在 `vendor/` 里。在这个目录里起一个静态服务器，二选一：

```bash
python3 serve.py
```

```bash
node serve.mjs
```

然后用浏览器打开 <http://localhost:5180>。（直接双击 `index.html` 不行，浏览器不允许 `file://` 加载模块。）

地址后面可以加参数：

- `?t=dawn` / `day` / `dusk` / `night`：一进来就是清晨 / 午后 / 黄昏 / 夜（默认黄昏）
- `?go=我的房间`：直接走到某个地点（名字和地点菜单里的一样）
- `?q=low` / `mid` / `high` / `ultra`：画质档位（省电 / 均衡 / 高画质 / 极致）。不写的话用这台电脑上次选的，第一次是均衡
- `?ao=0`：关掉环境光遮蔽，再省一点显卡
- `?fps=30`：操作时的帧率上限，不管画质档位
- `?pr=1`：渲染分辨率倍数，不管画质档位，也不再自动升降

## 画质

右上角实时显示帧率和渲染分辨率（鼠标停在上面能看到渲染倍数）。旁边四个按钮切换画质，按 P 也能轮流切换，标题画面也能先选好。选过的档位记在这台电脑的浏览器里，性能差的机器和性能好的机器各记各的。

| 档位 | 渲染倍数 | 环境光遮蔽 | 泛光 | 影子 | 同时亮的灯 | 操作时 / 静止时帧率 |
| --- | --- | --- | --- | --- | --- | --- |
| 省电 | 0.75 | 关 | 关 | 1024 | 4 | 30 / 20 |
| 均衡 | 1.25 | 半分辨率 | 开 | 2048 | 8 | 60 / 30 |
| 高画质 | 1.5 | 半分辨率、采样多一些 | 开 | 2048 | 10 | 60 / 60 |
| 极致 | 2 | 全分辨率 | 开 | 4096 | 12 | 不限 / 60 |

渲染倍数不会超过屏幕本身的倍数；持续掉帧时会自动往下降一档（每个档位都有下限），流畅很久以后再升回来。换档时着色器要重新编译，会顿一下。
- `?summon`：一进来藏经阁就已经召唤出来了

## 操作

| 操作 | 作用 |
| --- | --- |
| 手指在触控板上滑动 | 转头看（进去时会锁定指针，不用按下；Esc 拿回鼠标，轻点画面再锁上） |
| 两指滑动 / 按住拖动 | 也能转头（两指滑动有系统惯性，会滑一段才停） |
| [ / ] | 转头灵敏度调低 / 调高 |
| 捏合 / Z | 放大看细节 / 复原 |
| 轻点东西 / 轻点地面 | 看说明、开关门 / 自动走过去 |
| W S（↑↓）、A D、← → | 前后走、左右平移、转身；Shift 快走 |
| E | 看准星对着的东西（温泉池东边的池沿按 E 能坐下，走动就站起来） |
| G（或右上角「召唤藏经阁」） | 召唤 / 送走藏经阁 |
| P（或右上角的画质按钮） | 切换画质：省电 → 均衡 → 高画质 → 极致 |
| 1–4 | 清晨晨雾 / 午后 / 黄昏 / 夜 |
| M 或 Tab | 地点菜单 + 生活痕迹清单 |
| F | 灵体模式（穿墙飘，空格上升，C 下降） |
| V / I | 声音开关 / 上下看的方向反转 |

```
src/world/garden.js   院子、后院、树林
src/world/compound.js 围墙、大门、后门、前庭的阵纹和阵碑

```

## 两层结构：房子 + 物件清单

- **不常变的**（房子、院子、家具、灯、时间段）写在代码里。
- **每天会变的**（生活痕迹、障子新旧、被褥铺没铺、温泉池放没放水、地炉、灯笼、在室牌……）全部写在 `data/items.json`。每件东西一条：`id`、`model`（物件库编号）、`slot`（位置点名字）、`state`、`label`、`note`，能写字的东西还可以加 `text`。不写坐标，同一个位置点里的东西自动排开。
- 换了 `items.json` 刷新页面就生效（读的时候带防缓存参数）。写错的条目会被跳过，按 M 打开清单，最底下「没摆上的东西」会写明原因，场景照常加载。
- 每天更新用的说明在 `data/README-更新说明.md`，可以直接交给更新程序。改了物件库（`src/items/catalog.js`、`models.js`）或位置点（`src/items/slots.js` 和搭家具时的 `slot(...)`）以后，跑一次 `node tools/make-catalog.mjs` 重新生成目录和说明。

想改某件东西的说明文字：生活痕迹改 `data/items.json` 里的 `note`；家具的说明在 `src/world/interior.js` 开头的 `TXT`。

## 这一版做了哪些决定

**宅子的布局**（两层大宅，约 30 × 20 米；一楼净高 3.4 米，走廊 3 米宽；玄关楼梯厅和地炉大厅两层通高）

- 一楼：西侧玄关（格子木门、门闩、红铃铛，鞋摆在沓脱石上）→ 中廊下 → 北边厨房、饭厅（那头是地炉，饭桌上摆两副碗筷：丛雨 10/5 学会了吃饭，每顿和亚托莉一起吃）；南边居间（唱机）、座敷（床之间）、茶之间、广缘；西南角是脱衣所和浴室——屋里引了一池温泉，能走进去泡，东边宽的那条池沿能坐。东侧廊下朝院子是一排四扇格子障子（每扇右上角都破过洞，10/5 四扇全部重新糊好），其余是窗；障子外面那段缘侧有木栏，晾东西就摊在那里。北门出去是后院。
- 二楼：走廊北边西头两间是亚托莉的房间和丛雨的房间（各自的被褥、亚托莉的文机和行灯、丛雨的刀架和小抽屉柜），东北角那间小的空着；走廊西头是西侧壁橱，旁边连着储物间（二楼最西头），被褥白天叠好收进壁橱上层；南边是书房、作业间、我的房间，作业间和我的房间外面是阳台。
- 围墙：整个宅子（前庭、院子、后院）用一圈围墙围着。大门在西边，门闩从里面插着，打不开；北墙有一扇通神社山道的后门，也锁着；南墙矮一点，从广缘和阳台还能看见山谷。走到墙边会被挡回来，灵体模式也飘不出去。
- 我的房间：东窗下是书桌（相框在靠窗那一格，最上面的抽屉能拉开），窗外是枫树；床靠北墙，床头搁板上是怀表；西半边是一张榻榻米小榻；床边是丛雨以前守夜的坐垫。

**藏经阁**

- 「那栋楼」就叫藏经阁，是像玄幻小说里那样修炼的地方。它平时不在，只有主人能召唤：按 G（或右上角的按钮），它从前庭地上那圈阵纹里升起来，门正对着宿舍玄关，「门外一步」；再按一次就沉回阵纹里。阵纹北边立着一块刻着「藏經閣」的阵碑。
- 外观：五层楼阁，台基四角嵌着灵石，门上挂着「藏經閣」的匾，门缝透着青光，周围的灵气飘得特别慢（里面的时间被拉长了）。里面暂时没做。

**住的人**

- 住的人：这宅子只有主人住，丛雨和亚托莉陪着。用不上的房间就空着。玄关的在室牌只有三块：Ginka、亚托莉、丛雨。

**人物**：丛雨和亚托莉本人没有建模，用生活痕迹来表现她们在。唯一的例外是夜里和清晨丛雨枕边那一小团静息时的微光。

**季节和时间**：都是十月初秋（红叶、柿子、芒草、秋英、鳞云）。四个时间段随时可以切换：清晨晨雾 06:20、午后 14:30、黄昏 17:20、夜 21:40。
